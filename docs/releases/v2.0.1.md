# Trae Meta v2.0.1

发布日期：2026-10-13  
发布类型：正式版（问题修复与体验优化）  
签名状态：未签名，Windows SmartScreen 可能提示未知发布者

## 本次更新

- 修复：切换账号时面板连接中断（ECONNRESET）会导致后台服务整体崩溃退出的问题。
- 切换账号更快：关闭 TRAE 改为一次性强制退出，去掉数秒等待，消除了重复启动 PowerShell 造成的延迟。
- 登录更简洁：只保留无感登录，取消多余的「退出登录」入口与登录方式选择弹窗；切换与登录互斥。
- 「关于」页补充积分到期提醒、TRAE 自动更新开关、网络代理等说明。
- README 与 device-identity 文档同步更新。

## 已知限制

- 未签名，Windows SmartScreen 可能提示未知发布者。
- 「检查更新」需要能访问 GitHub；网络受限时请在设置页「网络」里配置代理，更新会走同一个代理。
- 当前仅支持 Windows 10/11 x64 与合并版 `Trae CN`。
- 手动续签会让同一账号在其他设备上的登录信息失效，仅在有意为之的场合使用。
- 代理认证只支持用户名 + 密码，不支持 NTLM / Kerberos。
- 代理账号密码在本机为明文存放，请勿外发 `data/config.json`。
