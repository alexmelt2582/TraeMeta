# Trae Meta v2.0.0

发布日期：2026-10-11  
发布类型：正式版（重要更新）  
签名状态：未签名，Windows SmartScreen 可能提示未知发布者

## 本次更新

- 适配 2026 年 10 月官方合并后的新版 `Trae CN` 客户端。此前面向 `TRAE SOLO CN` 与 `TraeCode CN` 的增强能力，现在统一由本助手提供。
- 更名为「Trae Meta」。安装目录、快捷方式、托盘与服务端口与旧版互不冲突，可与旧版并存。
- 面板图标和面板都可以拖动：拖到顺手的位置后会被记住，重开后仍在原处；面板会自动选有空间的一侧展开。
- 打开助手更快：启动时不再串行等待，更快看到界面。
- 日志时间改为北京时间（此前比本机时间早 8 小时）。
- 「检查更新」指向新的发布仓库，升级包命名同步为 `TraeMeta-Setup-<版本>.exe`。

## 已知限制

- 点击托盘图标或桌面快捷方式时，仍可能无法把 TRAE 主窗口带到最前面；遇到这种情况请到任务栏点一下 TRAE 窗口。
- 安装包未签名，Windows SmartScreen 可能提示未知发布者。
- 「检查更新」需要能访问 GitHub；网络受限时请在设置页「网络」里配置代理，更新会走同一个代理。
- 当前仅支持 Windows 10/11 x64 与合并版 `Trae CN`。
- 手动续签会让同一账号在其他设备上的登录信息失效，仅在有意为之的场合使用。
- 代理认证只支持用户名 + 密码，不支持 NTLM / Kerberos。
- 代理账号密码在本机为明文存放，请勿外发 `data/config.json`。
