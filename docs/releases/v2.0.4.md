# Trae Meta v2.0.4

发布日期：2026-10-17  
发布类型：正式版（稳定性修复）  
签名状态：未签名，Windows SmartScreen 可能提示未知发布者

## 本次更新

### 修复
- 修复选择项目后增强助手面板消失且不再出现的问题。现在守护进程会持续确认面板状态，面板一旦丢失会在约 1 秒内自动恢复，无需重启或手动重注入。
- 修复安装新图标后，其他软件的 Windows 通知可能错用本产品图标的问题：安装时会向 Windows 登记本产品的通知身份，托盘通知固定使用该身份，并在每次安装完成后自动刷新系统图标缓存，多台机器无需逐台手动处理。
- 修复切换账号时偶发的「TRAE 关闭后无法拉起」问题：停止或重启 TRAE 偶发失败时现在会自动重试一次，仍然失败会在面板给出明确提示，后台日志完整记录原因，不再静默失败。
- 面板自动恢复失败时会在后台日志中留下记录，便于排查。

## 已知限制

- 未签名，Windows SmartScreen 可能提示未知发布者。
- 「检查更新」需要能访问 GitHub；网络受限时请在设置页「网络」里配置代理。
- 当前仅支持 Windows 10/11 x64 与合并版 `Trae CN`。
- 手动续签会让同一账号在其他设备上的登录信息失效，仅在有意为之的场合使用。
- 代理认证只支持用户名 + 密码，不支持 NTLM / Kerberos；代理账号密码在本机为明文存放，请勿外发 `data/config.json`。
